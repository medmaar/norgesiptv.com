Sett opp NorgesIPTV på Pi

1

Installer LibreELEC på Raspberry Pi

Last ned LibreELEC fra libreelec.tv. Brenn til SD-kort med Raspberry Pi Imager. Sett SD-kortet i Pi, koble til TV via HDMI og start opp. Kodi starter automatisk.

2

Aktiver PVR IPTV Simple Client

I Kodi: Innstillinger → Tillegg → Mine tillegg → PVR-klienter → PVR IPTV Simple Client → Aktiver. Gå til Innstillinger → M3U spillelisteplassering → lim inn NorgesIPTV M3U-URL.

3

Legg inn EPG-URL

I PVR IPTV Simple Client: EPG → XML TV-URL → lim inn XMLTV EPG-URL fra NorgesIPTV-e-posten. Dette gir full 7-dagers programguide for alle kanaler.

4

Se IPTV i Kodi på Raspberry Pi

Gå til Kodi-hjem → TV → Kanaler. Alle NorgesIPTV-kanaler vises med kategori. EPG-guide vises under TV-guide. Fungerer med Firestick-lignende fjernkontroll via CEC.

FAQ

Vanlige spørsmål

Kan jeg bruke Raspberry Pi som IPTV-boks?+
Ja! Raspberry Pi 4 og Pi 5 med LibreELEC/Kodi er en utmerket IPTV-boks. Installer PVR IPTV Simple Client-pluginen og legg inn NorgesIPTV M3U-URL. Du får full EPG, live TV og VOD.
Hva er beste OS for IPTV på Raspberry Pi?+
LibreELEC er det beste operativsystemet for Raspberry Pi IPTV. Det er et minimalistisk Linux-OS optimert kun for Kodi. Alternativt: OSMC (OpenSource Media Center) som er litt mer fleksibelt.
Støtter Raspberry Pi 4K IPTV?+
Raspberry Pi 4 støtter 4K via HDMI 2.0. For 4K IPTV trenger du Pi 4 eller Pi 5. Pi 3 håndterer 1080p HD IPTV uten problemer.
Hva er PVR IPTV Simple Client?+
PVR IPTV Simple Client er en Kodi-plugin (PVR = Personal Video Recorder) som legger til live TV via M3U-URL. Det er standard-måten å kjøre IPTV i Kodi – inkludert NorgesIPTV.

NorgesIPTV på Raspberry Pi

1

Installer LibreELEC med Kodi

Flash LibreELEC (Kodi-basert OS) til microSD-kort. Boot Raspberry Pi 4/5 fra kortet. Kodi starter automatisk. LibreELEC er det beste operativsystemet for Pi-basert IPTV-bruk.

2

Legg til PVR IPTV Simple Client

I Kodi: Legg til → PVR klienter → PVR IPTV Simple Client → Installer. Under innstillinger: legg inn M3U-URL fra NorgesIPTV under «General → M3U spilleliste URL».

3

Legg inn EPG fra NorgesIPTV

Under PVR IPTV Simple Client → EPG-innstillinger: legg inn NorgesIPTV sin XMLTV EPG-URL. Da får du full programguide for alle 50 000+ kanaler i Kodi på Raspberry Pi.

4

Alternativ: Kodi på Raspberry Pi OS

Installer Kodi direkte på Raspberry Pi OS (Debian) via «sudo apt install kodi». Deretter installerer du PVR-pluginen via Kodi-grensesnittet. Gir mer fleksibilitet enn LibreELEC.

Raspberry Pi for IPTV

Pi 4 vs. Pi 5 – hvilken er best til IPTV?

🥇

Raspberry Pi 5

Pi 5 er den kraftigste Pi-en og håndterer 4K H.265/HEVC og AV1 IPTV via Kodi/LibreELEC uten problemer. Rask nok for smooth EPG-scrolling og kanalbytte. Anbefales for 4K NorgesIPTV.

🥈

Raspberry Pi 4

Pi 4 klarer Full HD IPTV uten problemer. 4K fungerer på enkle kanaler men kan streve med tungere H.265-strømmer. God nok for de fleste NorgesIPTV-brukere med Full HD-TV.

🔄

Vurder Firestick i stedet

For IPTV-bruk er Amazon Firestick 4K Max enklere og billigere enn Pi 5. Firestick gir bedre IPTV-opplevelse out-of-the-box med TiviMate – ingen konfigurasjon nødvendig.
