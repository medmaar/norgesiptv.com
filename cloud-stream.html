Vanlige spørsmål

Ofte stilte spørsmål

Hva er Cloud Stream?+
Cloud Stream er en IPTV-spiller-app for Android og Android TV. Den støtter M3U-spillelister og Xtream Codes API, og er kjent for rask ytelse og brukervennlig grensesnitt.
Er Cloud Stream gratis?+
Ja, Cloud Stream er gratis å laste ned i Google Play Store. Du trenger et IPTV-abonnement som NorgesIPTV for å se faktiske TV-kanaler.
Fungerer Cloud Stream på Fire TV Stick?+
Cloud Stream er primært for Android. For best opplevelse på Firestick anbefaler vi TiviMate eller IPTV Smarters Pro som er spesielt tilpasset Fire TV.
Støtter Cloud Stream norsk EPG?+
Ja, Cloud Stream støtter EPG fra NorgesIPTV. Programguiden lastes automatisk når du legger inn dine innloggingsdetaljer.
Kan jeg bruke Cloud Stream med NorgesIPTV?+
Absolutt. Legg inn M3U-URL eller Xtream Codes-detaljer fra NorgesIPTV i Cloud Stream for øyeblikkelig tilgang til 50 000+ kanaler.
