🔑

Server-URL + innlogging

Xtream Codes gir deg en server-URL (f.eks. http://server:port), brukernavn og passord. Disse legges inn én gang i IPTV-spilleren.

⚡

Dynamisk oppdatering

Kanallisten hentes direkte fra serveren i sanntid. Nye kanaler og EPG oppdateres automatisk – ingen manuell oppdatering av M3U-fil.

📅

Full EPG via XC

Xtream Codes leverer også EPG-programguide direkte. Spillere som TiviMate viser automatisk hva som er på alle kanaler.

🎬

VOD via Xtream

Alle 120 000+ filmer og serier i NorgesIPTV er tilgjengelig via Xtream Codes API under VOD-seksjonen i spilleren.

🔒

Kryptert tilgang

Xtream Codes-tilgang er personlig og kryptert. Deler ikke en åpen URL – sikrere enn statiske M3U-lister.

📱

Fungerer på alle enheter

FAQ

Vanlige spørsmål om Xtream IPTV og XC Codes

Hva er Xtream Codes API for IPTV?+
Xtream Codes (XC) er et API-format for IPTV-tilgang via server-URL, brukernavn og passord. Det er raskere og mer stabilt enn M3U-spillelister fordi kanallisten oppdateres dynamisk.
Hva er XC IPTV?+
XC IPTV er forkortelsen for Xtream Codes IPTV. Det er den foretrukne tilgangsmetoden for TiviMate, IPTV Smarters Pro og OTT Navigator. NorgesIPTV leverer XC-innlogging til alle abonnenter.
Hva er forskjellen på Xtream IPTV og M3U?+
Xtream IPTV bruker API (server + brukernavn + passord) og oppdaterer kanallisten automatisk. M3U er en statisk URL-fil. Xtream anbefales for TiviMate og Smarters Pro; M3U er enklere for Smart TV-apper.
Fungerer Xtream Codes med TiviMate?+
Ja, TiviMate bruker primært Xtream Codes API. Åpne TiviMate → Legg til spilleliste → Xtream Codes API. Skriv inn NorgesIPTV sin server-URL, brukernavn og passord.
Kan jeg bruke XCIPTV-appen med NorgesIPTV?+
Ja, XCIPTV (også kjent som iptvx eller xc iptv app) støtter Xtream Codes API og fungerer perfekt med NorgesIPTV på Android TV og mobil.
